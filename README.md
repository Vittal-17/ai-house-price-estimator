# 🏠 AI House Price Estimator

A full-stack AI application built with React, FastAPI, and Scikit-learn to predict California housing prices using a tuned Random Forest Regression model.

## Tech Stack

- React + Vite
- Tailwind CSS
- FastAPI
- Scikit-learn
- Random Forest Regression
- Axios

## Features

- AI-powered house price prediction
- Demo mode
- Prediction history
- Responsive UI
- Toast notifications
- Model performance summary
